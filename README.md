# EOG-Based Calculator

The EOG-Based Calculator is a Human-Computer Interaction (HCI) project that allows users to control a calculator using eye movements and blink detection through Electrooculography (EOG) signals. The system captures and processes eye movement signals to perform calculator operations without using traditional input devices such as keyboards or mice.

This project focuses on accessibility and assistive technology by providing a hands-free interaction method for users with limited motor abilities. It demonstrates the integration of signal processing, pattern recognition, and user-centered interface design in real-world HCI applications.

## Features
- Eye movement–based calculator control
- Blink detection for command selection
- Hands-free user interaction
- EOG signal processing and classification
- Accessible and user-friendly interface

## Technologies & Concepts
- Human-Computer Interaction (HCI)
- Electrooculography (EOG)
- Signal Processing
- Machine Learning / Classification
- Assistive Technology

## Objective
The main goal of this project is to create an intuitive and accessible calculator system that improves user interaction through biometric eye signals, offering an alternative communication and control method for users with physical disabilities.
